A bug-fix release of the open graphics stack for the PowerVR SGX545 in Intel's Cedarview
Atoms (N2600, N2800, D2500, D2550, D2700), the Intel Atom CE5300, and now Intel's Clover
Trail (Atom Z2760). It fixes a memory leak, large offscreen images, and several of the
games testers reported on 0.2.1. Thanks to everyone who sent logs, screenshots and fixes.

**Upgrade the kernel, the firmware and Mesa together, then restart.** The interface between
the kernel driver and Mesa hasn't changed since 0.2.1, so 0.2.2's Mesa also runs on the 0.2.1
kernel.

## What's fixed

- **A memory leak in every GL program.** Buffers the driver reused were never freed until the
  program exited. On Minecraft's title screen, GPU memory grew from 190 to 588 MB in three
  minutes. It now stays flat at about 117 MB.
- **Offscreen images larger than 1440x960** were only partly drawn, and each one left memory
  behind, so games got slower until the GPU stopped with a timeout (issue #5's FBO slowdown,
  found by danilolc).
- **Games:**
  - **Half-Life 2 and other Source games:** the main world shaders lost their values, which
    is the likely cause of the black screen. Vertex shaders can also use 256 constants now,
    up from 128. This hasn't been tried in a Source game yet, so please tell us how it goes.
  - **Portal and other games that set color masks per render target:** `GL_EXT_draw_buffers2`
    and `GL_ARB_draw_buffers_blend` are supported now.
  - **OpenArena and ioquake3 with `r_PreferOpenglES 1`:** the shaders compile now, and the
    game starts.
  - **Minecraft:** the title-screen panorama shows in full. Frames that render several
    offscreen images are faster (13 to about 17 FPS in our test scene).
- **Xfce with the Mint-Y theme:** window borders were drawn dashed (issue #13).
- **Texture updates of part of a texture** are faster.
- **A crash** in programs with matrix varyings or attributes (found by servidorjarvis1-svg).
- **Clover Trail (Atom Z2760) is supported**, contributed and tested by servidorjarvis1-svg on
  an HP ElitePad 900.

## Upgrading

**From 0.2.x, with the apt repository:**

```bash
sudo apt update && sudo apt upgrade
```

Then restart. With the 32-bit package (`mesa-sgx:i386`), `apt upgrade` updates it too.

**From 0.1.x or from test builds:** see the 0.2.0 notes, "Upgrading", and install 0.2.2
instead of 0.2.0.

**CE5300 (DKMS), Clover Trail, and Cedarview with DKMS:** rebuild the driver from this
release's source as in docs/INSTALL.md, section 2.

## Tested

0.2.2 has been tested on CE5300 boards and on a Clover Trail tablet, **but not yet on a
Cedarview desktop.** If you run it on a Cedarview machine, please tell us how it goes on
issue #5, good or bad.

- **On CE5300 boards**, with the 0.2 kernel and its open microkernel:
  - each fix above with its own test;
  - dEQP-GLES2's shader, uniform, indexing and limits groups, the same as before these
    changes;
  - the Mesa test suite in CI for every change.
- **On the Clover Trail tablet:** the kernel driver, glmark2, `glxgears`, mpv, and dEQP's
  shader linkage tests.

## Known issues

- **No OpenGL 3.x or OpenGL ES 3.0 yet.** The driver offers OpenGL 2.1 and OpenGL ES 2.0.
  Chrome and Firefox need more, so they fall back to software rendering.
- **3D textures** larger than one texel aren't supported yet.
- **GTA Vice City under Wine** flickers. This is being investigated.
- **Counter-Strike 1.6 in OpenGL mode** runs slower than its software renderer. This is
  being investigated.
- **ioquake3's `opengl1` renderer** can leave a map's world undrawn on a CE5300 board.
- **sRGB textures:** filtering across mipmap levels and sRGB border colors aren't right yet.
- **Each GL program uses about 38 MB more GPU memory** than in 0.2.1, for the faster frames.
  `SGX_SLOTS=4` brings back 0.2.1's setting.
- **The same as 0.2.1:**
  - `perf record` with precise events (PEBS) can corrupt memory on these Atoms; use
    `perf record -e cpu-clock`.
  - Some Cedarview panels stay dark with `gma500`, with Debian's kernel too.
  - CE5300 boards have no kernel package (DKMS only).

## Installing

New installs: docs/INSTALL.md. Check the downloads with `sha256sum -c SHA256SUMS`.

Please report problems on the issue tracker, with your computer model and the output of
`sudo dmesg | grep -i -E 'powervr|gma500|drm'` and `glxinfo -B`.
